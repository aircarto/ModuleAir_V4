ModuleAir

Configuration WiFi de votre capteur

Navigateur non compatible

Le Bluetooth Web n'est pas disponible sur ce navigateur. Utilisez Chrome ou Edge sur Android ou ordinateur. Sur iPhone/iPad, suivez la méthode alternative ci-dessous.

Connecter votre ModuleAir au WiFi

1
Allumez votre ModuleAir et attendez quelques secondes
2
Cliquez sur le bouton ci-dessous
3
Sélectionnez votre ModuleAir dans la liste des appareils Bluetooth
4
Entrez le nom et le mot de passe de votre réseau WiFi

iPhone / iPad ou Bluetooth indisponible ?

Connectez-vous au réseau WiFi ModuleAir-XXXXXX avec le mot de passe moduleaircfg, puis ouvrez 192.168.4.1 dans votre navigateur pour configurer le WiFi.
